Descripción del Proyecto

Esta aplicación demuestra una animación interactiva utilizando funciones trigonométricas en un elemento Canvas HTML5. Modifica simultáneamente dos propiedades principales:

  • Posición (X, Y): Calculada combinando las funciones Math.cos() y Math.sin() para generar un movimiento orbital armónico suave.
  • Escala: Calculada independientemente usando Math.sin() con una frecuencia y desfase específicos para aplicar un pulso constante al objeto.

Fórmulas Aplicadas

X = CentroX + Cos(Ángulo) × AmplitudX
Y = CentroY + Sen(Ángulo) × AmplitudY
Escala = EscalaBase + Sen(Ángulo × Frecuencia) × FactorEscala
